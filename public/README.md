# public

Static files served from the site root.

- `sites/industrias-maral/`: product and campaign images used by the catalog and home page (validated copies of the public catalog images).
- `sites/syscom-colombia/`: only the Satoshi variable font (`Satoshi-Variable.woff2`), loaded by `globals.css`.
- `images/`, `seo/`, `videos/`: placeholders (`.gitkeep`) for future assets.
