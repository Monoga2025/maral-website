# components

- `cart/`: cart provider (client state), cart and checkout views, add-to-cart buttons, quick add to quote.
- `catalog/`: catalog explorer, filters, product cards, price display, shop hero, frequency scale.
- `home/`: hero, band finder, product rails, stat band, bento and "how it works" sections, scroll reveal.
- `product/`: product stage, buy panel and related products.
- `site/`: header, footer, route chrome (announcement and WhatsApp floating button) and custom element typings.
- `account/`: login and registration demo forms. They show a notice and store nothing.
- `ui/`: button primitive.
