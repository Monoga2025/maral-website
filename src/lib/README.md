# lib

- `catalog.ts`: imports `docs/research/industrias-maral/catalog.json` and exposes typed products, slugs, categories and `formatPrice` / `priceOf`.
- `quote.ts`: quote totals (units, published subtotal, count of items to quote) and the message text sent to WhatsApp.
- `site.ts`: contact constants (placeholders in this copy) and `whatsappUrl(text)`.
- `utils.ts`: class-name helper.
