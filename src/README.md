# src

- `app/`: App Router pages (home, shop, category, product, cart, checkout, contact, and redirects for account routes). See `app/README.md`.
- `components/`: cart, catalog, home sections, product view, site chrome, account forms and UI primitives. See `components/README.md`.
- `lib/`: catalog loader, quote-message builder, site contact constants and utilities. See `lib/README.md`.
- `styles/`: layered CSS for tokens, the home page and the shop. See `styles/README.md`.
- `hooks/`, `types/`: currently empty placeholders (`.gitkeep`).
