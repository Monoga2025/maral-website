## Qué es este proyecto
- Sitio ecommerce/cotizador para **Maral Tecnología y Comunicaciones S.A.S.** (antenas de radiocomunicación, Curití, Santander).
- Nació como clon de SYSCOM Colombia (`/clone-website`) y se transformó en el sitio de Maral reutilizando la arquitectura comercial de SYSCOM (búsqueda, categorías, ficha, cotización).
- Stack: Next.js 16 (App Router, React 19, TS strict). Leer `AGENTS.md`: esta versión de Next tiene cambios incompatibles.
- La carpeta `08_MARAL/` está en `.gitignore` del repo raíz: **nada de esto está versionado en git**. Borrar es irreversible.

## Cómo correrlo
```
npm run dev        # http://localhost:3000
npm run typecheck
npx eslint src --quiet
npm run build
```
El equipo se queda sin memoria con facilidad (Monoga OS con `turbo`, sesiones de Codex, varios `codegraph`). Cerrarlos antes de `npm run dev`.

Capturas fiables: Chrome headless (la ventana no baja de ~500 px, usar 520 para móvil):
```
"C:\Users<user>\AppData\Local\Google\Chrome\Application\chrome.exe" --headless=new --disable-gpu --hide-scrollbars --user-data-dir=<tmp>\prof --window-size=1440,7000 --virtual-time-budget=9000 --screenshot=<tmp>\home.png http://localhost:3000/
```
Luego recortar con ffmpeg (`crop=1440:1200:0:Y,scale=960:-1`) para leer por partes.
