# Industrias Maral Original Storefront Preview

## Objective
Create a distinct, responsive Maral storefront preview at `/maral` inside `08_MARAL/Pagina Web Maral`, using verified company/product facts from `https://industriasmaral.com` while creating original copy, visual composition, and implementation. Preserve the existing SYSCOM clone at `/` and its current routes until the user explicitly chooses a later switch.

## Why and decisions
- The user authorized adapting the existing app for Industrias Maral, explicitly requested a plagiarism-safe design, and selected a separate `/maral` preview to preserve the existing SYSCOM site.
- The app is ignored by the parent Git repository and has no nested `.git`; replacing its root would not have an automatic Git rollback. No existing source routes or assets will be deleted.
- Direct anonymous fetch of `https://industriasmaral.com` returned a React/Vite application bundle titled “Maral | Tecnología y Comunicaciones.” Static text inspection (no source JavaScript execution) exposed 52 product entries across seven categories and contact details. Search-engine results were stale/inconsistent with the direct fetch.
- Use company facts, reference/SKU/specification data, and official public Maral logo/product assets only after validating asset types. Do not copy the site's HTML, JS bundle, CSS, exact page composition, animations, or promotional paragraphs; write original UI copy and a distinct layout.
- Public contact evidence: `573000000002`, `user37@example.com`, Curití, Santander, Colombia. The existing source links quote requests to WhatsApp. These are observed source facts, not independently audited.
- Prices are present for some catalog entries and absent for others. Preserve exact published values in source data with a visible “confirm current price” qualifier; never invent price or inventory/availability.
- Quote actions must be deliberate user clicks that open a prefilled WhatsApp message. No payment, customer account, order submission, backend, or automatic outbound message. Use an isolated local quote-list key; never read the SYSCOM `maral-local-cart` key.
- No deployment, DNS/domain, credentials, or remote mutation is authorized. Existing user preference: no commits.

## Authorized scope
- Add a Maral-only route tree under `src/app/maral/` and Maral-specific components/data/styles.
- Add a route-aware shell switch only as needed to hide the existing SYSCOM header/footer and cart provider on `/maral`; preserve the behavior of `/` and current SYSCOM routes.
- Capture and document public Maral product/media assets under `public/sites/industrias-maral/` and `docs/research/industrias-maral/`.
- Keep all prior SYSCOM app source/data/assets intact; do not edit the unrelated parent workspace files.

## Non-goals
- Reproducing the existing Maral site's appearance or text verbatim.
- Replacing the root app, removing the SYSCOM preview, publishing, deploying, changing DNS, or integrating private commerce/authentication systems.
- Claiming live stock, guaranteed fulfillment, audited company claims, or pixel-perfect parity without evidence.

## Acceptance criteria
- `/maral` renders a coherent original Maral landing page and branded navigation/footer without the surrounding SYSCOM shell; `/` remains unchanged and its old cart state cannot leak into Maral.
- A local, provenance-documented catalog has the 52 observed Maral references, correct categories and source URLs; only validated first-party assets are referenced.
- Maral catalog search/category/frequency filtering and product-detail navigation work; technical specs and published prices are represented faithfully, with price freshness qualified and no stock invented.
- Quote-list behavior is deterministic and isolated; an explicit final CTA opens WhatsApp to the observed Maral number with an encoded summary, and nothing is sent automatically.
- Responsive layout, keyboard/focus states, semantic controls, and no horizontal overflow at desktop/mobile widths.
- `npm run check`, deterministic helper tests (use the built-in Node test runner; package has no test script/framework), production route smoke checks, and product-asset GET checks pass. Browser visual comparison is only claimed if a browser becomes available.
